# V0.2 桌面版验证记录

## 已实现

- PySide6 中文主窗口：路径输入/文件选择、视频参数、开始/取消、进度条、异常表格及汇总。
- QThread 后台执行统一 AnalysisEngine；界面通过信号接收参数、进度、结果及错误。
- 线程安全取消事件；引擎在解析与帧处理边界检查取消，释放资源，不返回部分成功结果。
- 关闭窗口先取消并等待任务结束；不使用强制 terminate 或在主线程 wait。
- 防止重复启动；更换文件清空旧结果；失败和取消后可再次运行。
- Windows FFprobe 子进程隐藏控制台窗口。

## 自动化结果

完整运行 `python -m pytest -q`：**71 passed in 42.42s**，无跳过。

后续隐藏 FFprobe 控制台调整后，针对 GUI 与 FFprobe 重跑：**10 passed in 16.21s**。

新增覆盖：

1. 进度首尾与 Metadata 回调。
2. 开始前取消与读取中取消；回调失败也释放资源。
3. Qt 真实后台线程分析编码视频，输出黑屏与冻结；重复分析不叠加结果。
4. 路径切换清除旧结果；无效文件与后台错误恢复。
5. 分析期间 Qt 定时器持续触发，验证事件循环响应。
6. 点击取消、分析中关闭窗口、取消与成功信号同时入队的竞争处理。

## 当前边界

- 取消需等待 FFprobe（最多 30 秒）或当前解码调用返回，不保证瞬间取消；解码器长期阻塞时关闭也需等待。
- 原算法限制保留：CFR 时间模型、静态 PPT 冻结误报、真实会议素材尚待验证。
- V0.3 再实现截图与视频跳转；当前不含视频播放器、持久化或报告导出。
- `requirements-gui.txt` 为可选依赖；本次环境 PySide6 6.12.0。仅安装基础依赖会跳过 GUI 测试。
