# V1.0 重构与材料验证

日期：2026-10-21。软件名称：智能会议设备投屏质量分析系统，V1.0。

## 本轮实现

- 按用户选择保留 PySide6，主界面改为可拖动三栏：项目任务树、分析及图表、所选事件详情。默认最大化。
- 新增异常时间轴、事件持续时间、时长构成、人工复核四类真实统计图。区间去重复用质量评分计算，人工复核独立保存。
- 修复同一源视频不同历史任务切换后的复核状态残留，改善长项目名、长文件名及 1100×720 布局。
- 显式设置控件背景，修复 Windows 深色主题下详情与弹窗文字对比不足。导出状态显示文件名，完整路径放在提示中。
- 软件入口、窗口、任务版本、Excel 报告及便携包统一使用产品版本常量。
- 新增真实窗口自动截图、可追溯源程序导出、使用说明和软件信息表生成工具。Windows 截图采用本应用窗口的 PrintWindow，避免混入其他应用通知；离屏或单色捕获会失败。

## 源码测试

完整回归：`python -m pytest -q`，**182 项通过，无跳过，退出码 0，71.70 秒**。

随后对排版生成器与工作台运行 15 项测试通过；排版参数调整后生成器 6 项再次通过；Excel 版本常量调整后报告相关 11 项通过。最终版本完整回归 **182 项通过，无跳过，退出码 0，64.68 秒**。

新增验证覆盖真实零事件与无结果区别、区间裁剪与重叠扣除、四图绘制、任务树载入、同源历史任务复核刷新、筛选清除详情、忙时任务切换限制、长名称布局和源码排版映射及源码包内容。

## 实际编码视频与窗口验证

使用 `samples/最终验收 1080p.mp4`：60 秒、1920×1080、30 FPS，实际读取 **1800 帧**；检出黑屏 **2 段共 3 秒**、疑似冻结 **2 段共 5 秒**，辅助评分 **90.83**。该视频是确定性合成验证图，不能据此计算真实会议场景准确率。

自动流程实际完成分析、项目创建、复核状态保存、事件画面跳转及逐帧移动、截图保存、四图切换、筛选、任务改名和移动、历史打开、Excel 导出，采集 19 张真实窗口图，手册使用其中 18 张。截图仅含本应用窗口，采用独立演示数据库，未改动默认用户历史。

## Windows 便携包

本机 Windows 11 x64、Python 3.11.2、PyInstaller 6.22.3 构建。携带 FFprobe 5.1.2、GUI 与 CLI 入口以及组件版本和许可证。

在仅含 Windows System32 的 PATH 下，便携包 CLI 的 UTF-8 JSON、中文视频路径、SQLite 任务与 Excel 导出通过；GUI 自检的历史打开、人工复核及报告导出通过，均得到 4 个事件与 90.83 分。显式指定不存在的 FFprobe 路径时正确失败。本轮最终包在版本号统一后重建并重新验证，结果与 SHA-256 记录在交付清单。

本机隔离验证不等同于独立无开发环境电脑验收；安装器、签名、自动更新、真实会议泛化评估和变帧率逐帧 PTS 定位仍待后续实现。

## 文档与源码材料

Word 和 PDF 对应：使用说明 18 页；源程序材料 57 页，因不足 60 页提交全量。原始运行源码 36 个文件、3816 物理行、3203 有效代码行；逐文件 MD5/SHA-256 和编号映射见 source_manifest.json。实际 PDF 非末页为 53 至 57 个有效代码行，编号与计划逐页一致。

使用 Word 的 ExportAsFixedFormat 实际渲染。已修正首次渲染发现的标题继承边框、流程图行高裁切和源码长行跨页问题。最终 PDF 的逐页行号必须与清单一致；非末页至少 50 个有效代码行，软换行不增加编号。原始源码字节不变，仍保留注释和正常结构。

保留 PySide6 等规范适配与未采用项见 `docs/materials-v1/specification_notes.txt`。材料不包含虚构研究结论、会议记录、作者身份或对登记结果的保证。
