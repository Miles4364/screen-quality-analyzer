# V0.9.1 内置 FFprobe

日期：2026-10-16。

Windows 便携包默认包含 `tools/ffprobe.exe`，无需用户配置 FFmpeg/PATH。保留 `SQA_FFPROBE` 显式覆盖能力；设置了无效覆盖路径时明确报错。

## 组件与产物

- FFprobe：5.1.2-essentials_build-www.gyan.dev，使用现有本地静态发行版，未修改二进制。
- 二进制 SHA-256：`702c7b51e4ac3001c7f8b451c9f03dca9f0e7e5f15d127e750e7a33fee2997f7`。
- 包名：`ScreenQualityAnalyzer-V0.9.1-Windows-x64.zip`，131,865,273 字节。
- ZIP SHA-256：`671b5bd73a5c81dfc360eae953333e1c5dc7fd435a1a6c2bda5cc3756f77dae3`。
- `licenses/FFprobe` 附原始 LICENSE、README.txt、运行时版本信息及二进制哈希；组件版本记录写入 build-versions.json。

构建时必须提供完整静态发行目录，缺少 exe/许可证/发行说明会失败；拒绝非静态或带 nonfree 配置的构建。隔离 PATH 执行 `-version` 预检，再复制原二进制，不复制 ffmpeg/ffplay。
