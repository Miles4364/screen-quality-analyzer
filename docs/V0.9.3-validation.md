- Windows 包在隔离 PATH、非 UTF-8 输出环境下完成 CLI 分析、入库、Excel 导出和 Qt 后台分析、人工复核、历史恢复、报告导出自检。60 秒 1080p 样本检出 2 段黑屏、2 段疑似冻结，评分 90.83；无效 FFprobe 覆盖配置明确失败。
